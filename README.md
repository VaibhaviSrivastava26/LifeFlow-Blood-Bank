# 🩸 LifeFlow – Blood Bank Management System

> **Every Drop Counts. Every Life Matters. ❤️**

LifeFlow is a web-based **Blood Bank Management System** developed to simplify blood donation, blood requests, blood stock management, and emergency blood requirements.

The project provides a user-friendly interface for donors, patients, and administrators to manage blood-related activities efficiently.

---

## 🌐 Project Overview

LifeFlow is designed to provide a centralized platform where users can:

- Register as blood donors
- Request blood
- Search for available blood groups
- View current blood stock
- Manage emergency blood requests
- Receive donor/request confirmations
- Allow administrators to manage blood requests
- Monitor blood inventory

---

## ✨ Features

### 👤 User Features

- User Registration
- User Login & Logout
- Blood Group Search
- Blood Stock Availability
- Blood Donation Registration
- Blood Request Form
- Emergency Blood Request
- Request Priority:
  - 🚨 Emergency
  - 🟠 Urgent
  - 🟢 Normal

### 🩸 Blood Bank Features

- Blood group-wise stock
- Available blood units
- Blood request management
- Donor management
- Blood availability search

### 🛡️ Admin Dashboard

The admin dashboard provides:

- Pending blood requests
- Approved requests
- Emergency requests
- Patient name
- Blood group
- Required units
- Hospital name
- Request priority
- Request status
- Approve/Reject actions
